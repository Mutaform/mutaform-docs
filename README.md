# mutaform-docs

Документация к студийным аддонам Mutaform для Blender.
Сайт: <https://mutaform.github.io/mutaform-docs/>

Репозиторий содержит только документацию. Исходники аддонов живут в своих
репозиториях и подтягиваются при сборке.

## Как это устроено

Документация делится на два слоя, и это главное, что нужно понимать при правках.

**Справочник** (`docs/*/reference.md`) генерируется из исходников аддонов
скриптом `tools/gen_reference.py`. Он разбирает Python через `ast`, без запуска
Blender, и вытаскивает панели, операторы, свойства, значения по умолчанию и
диапазоны. Эти файлы **править бесполезно** — следующая сборка их перезапишет.
Устареть они не могут по построению.

**Гайды** (`docs/*/index.md` и прочие) написаны руками. Они объясняют, зачем
аддон нужен и как им пользоваться, и меняются редко.

Русские описания для справочника лежат в `translations/<slug>.ru.yml` — это
единственное место, где справочник правится руками.

За тем, чтобы гайды не отстали от кода, следит `tools/check_drift.py`.

## Локальная работа

```bash
pip install -r requirements.txt
```

Пересобрать справочник из локальных исходников:

```bash
python tools/gen_reference.py --source-root "D:/Mutaform/Mutaform Addons"
```

Дорисовать заглушки под ещё не снятые скриншоты:

```bash
python tools/make_placeholders.py
```

Посмотреть сайт с горячей перезагрузкой на <http://127.0.0.1:8000>:

```bash
mkdocs serve
```

## Что делать после релиза аддона

Ничего. CI собирается по пушу в этот репозиторий, по расписанию раз в неделю и
по ручному запуску `workflow_dispatch` — последний удобно дёргать из релизного
workflow самого аддона.

Если в аддоне появились новые кнопки, сборка заведёт issue с меткой `drift` и
списком того, что нужно дописать в гайдах. Справочник при этом обновится сам.

## Чего не хватает

```bash
python tools/make_placeholders.py --list
```

покажет скриншоты, которые ещё не сняты.

```bash
python tools/check_drift.py --source-root "D:/Mutaform/Mutaform Addons"
```

покажет элементы интерфейса без русского описания и без упоминания в гайдах.

## Структура

```text
addons.yml              реестр аддонов: пути к исходникам и адреса репозиториев
shots.yml               чек-лист скриншотов
data/api-manifest.json  слепок UI-поверхности, по нему ловится дрейф
translations/           русские и английские описания для справочника
tools/
  extract.py            разбор исходников аддона через ast
  gen_reference.py      генерация справочника и страницы версий
  check_drift.py        сравнение кода с документацией
  make_placeholders.py  заглушки под скриншоты
docs/                   страницы сайта (ru — без суффикса, en — .en.md)
```

## Двуязычность

Русский — основной язык, он в корне сайта. Английский лежит в `/en/` и
собирается из файлов с суффиксом `.en.md`. Если английской версии страницы нет,
посетитель увидит русскую — сборка от этого не падает.
