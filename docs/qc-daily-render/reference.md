# Что делает каждая кнопка

Разбор панели QC Render. Пока студия не построена, всё содержимое вкладок серое — сначала Setup, потом настройки.

## Верх панели

Три кнопки, которые видно всегда. До Setup здесь только он один.

### Setup Render Scene / Render / Open Folder

![Setup Render Scene / Render / Open Folder](img/c/actions.png){ .control-shot }

До построения студии здесь одна кнопка **Setup Render Scene**. После — **Render** и **Open Folder**.

**Когда пригодится.** Порядок работы: Setup → ищете ракурс вьюпортом → Render. Камеру ставить не нужно, аддон сам создаёт её по текущему виду и убирает после съёмки.

**Что получится.** Setup строит студию: HDRI-свет, единый материал, ловец контактной тени, пост-обработку. Вьюпорт переключается в Rendered и показывает рамку будущего кадра — всё, что за ней, в снимок не попадёт. Render сохраняет PNG с прозрачным фоном и автонумерацией; вид во вьюпорте при этом не сдвигается. Open Folder открывает папку с готовыми кадрами.

!!! warning "Обратите внимание"
    Setup сам подбирает быструю конфигурацию под машину: лучший доступный бэкенд, только GPU без гибрида с процессором, persistent data. Всё это восстанавливается при выходе.

### Restore (exit)

![Restore (exit)](img/c/restore.png){ .control-shot }

Полностью откатывает сцену и выходит из студийного режима.

**Когда пригодится.** Когда кадры сняты. Не бойтесь нажимать: аддон запоминает состояние сцены при Setup и возвращает ровно его.

**Что получится.** Удаляется всё созданное, возвращаются материалы объектов, настройки рендера и выбор устройств.

### Camera Settings / Render Settings

![Camera Settings / Render Settings](img/c/tabs.png){ .control-shot }

Переключает панель между картинкой и техникой.

!!! warning "Обратите внимание"
    Пока студия не построена, содержимое обеих вкладок серое. Это не поломка — настраивать нечего, пока нет сцены.

## Camera Settings — как выглядит кадр

Всё, что влияет на картинку: материал, объектив, свет, цветокоррекция.

### Use Default Material

![Use Default Material](img/c/material.png){ .control-shot }

Рендерить всё одним студийным материалом вместо собственных материалов объектов. Ниже — его цвет, шероховатость и металличность.

**Когда пригодится.** Держите включённым для дейликов: модель читается по форме и силуэту, а не по текстурам, и все ассеты в ленте выглядят единообразно. Выключайте, когда показываете именно текстуры.

**По умолчанию:** включено

### Camera Settings (свиток)

![Camera Settings (свиток)](img/c/camera-fold.png){ .control-shot }

Раскрывает блок с объективом, светом и пост-обработкой.

**Когда пригодится.** Для обычного дейлика хватает значений по умолчанию — они подобраны под студийную подачу. Сюда лезут, когда кадр нужно довести.

**По умолчанию:** свёрнуто

### Field of View

![Field of View](img/c/fov.png){ .control-shot }

Вертикальный угол обзора в градусах.

**Когда пригодится.** Малое значение — это длиннофокусная подача почти без перспективных искажений, именно она делает кадр похожим на студийную съёмку, а не на скриншот вьюпорта. Увеличивать стоит, только если ассет не влезает или нужен нарочито широкоугольный вид.

**По умолчанию:** 15°

### HDRI Brightness и HDRI Rotation

![HDRI Brightness и HDRI Rotation](img/c/lighting.png){ .control-shot }

Яркость окружения и его поворот вокруг вертикальной оси.

**Когда пригодится.** Поворот — самый быстрый способ поправить кадр: меняются направление света и положение бликов, а модель остаётся на месте. Работает вживую, крутите и смотрите.

### Post Effect (свиток)

![Post Effect (свиток)](img/c/post-fold.png){ .control-shot }

Раскрывает цветокоррекцию.

**По умолчанию:** развёрнуто

### Tone Mapping и Curves

![Tone Mapping и Curves](img/c/tone.png){ .control-shot }

Способ свести яркости в отображаемый диапазон и кнопка точных кривых.

**Когда пригодится.** Tone Mapping меняют редко. Curves нужны, когда ползунков светов и теней не хватает — например, надо поднять только самые тёмные участки.

### Ползунки цветокоррекции

![Ползунки цветокоррекции](img/c/post-sliders.png){ .control-shot }

Экспозиция, света, средние тона, тени, локальный контраст, общий контраст с точкой раскрытия и насыщенность.

**Когда пригодится.** Clarity подчёркивает средние детали — на нём модель выглядит «резче», хотя резкость не менялась. Contrast Center задаёт, вокруг какой яркости раскрывается контраст: сдвиньте вниз, если тени уходят в чёрное.

!!! warning "Обратите внимание"
    У каждой строки справа кнопка со стрелкой — сброс к значению по умолчанию. Значения по умолчанию здесь не заводские блендеровские, а студийные, поэтому возврат к ним безопасен.

### Sharpen

![Sharpen](img/c/sharpen.png){ .control-shot }

Резкость с ограничителем.

**Когда пригодится.** Strength добавляет резкости, Limit не даёт появиться светлым ореолам по контурам. Если по краям модели полезла белая кайма — уменьшайте Limit, а не Strength.

### Frame Guide и Background

![Frame Guide и Background](img/c/frame-bg.png){ .control-shot }

Слева — насколько затемняется всё за пределами будущего кадра, справа — цвет подложки в превью.

**Когда пригодится.** Frame Guide помогает строить композицию прямо во вьюпорте: то, что затемнено, в кадр не войдёт.

!!! warning "Обратите внимание"
    Цвет фона виден только в превью. Итоговый PNG сохраняется с прозрачностью, и контактная тень попадает в альфу — кадр композится на любой фон. Здесь же находится свёрнутый свиток Vignette с силой и мягкостью затемнения по краям.

### Wireframe

![Wireframe](img/c/wireframe.png){ .control-shot }

Накладывает сетку модели поверх шейдинга. Ниже — цвет, толщина и непрозрачность линий.

**Когда пригодится.** Для дейлика, где надо показать топологию. Сетка рисуется по настоящим четырёхугольникам, без диагоналей триангуляции — то есть показывает то, что вы моделировали.

**По умолчанию:** выключено

## Render Settings — техника

Движок, размер кадра, качество и куда сохранять.

### Cycles / EEVEE

![Cycles / EEVEE](img/c/engine.png){ .control-shot }

Движок и для превью, и для сохраняемого кадра.

**Когда пригодится.** EEVEE — быстрый просмотр, когда надо покрутить ракурс на тяжёлой сцене. Финальный кадр снимайте в Cycles.

**По умолчанию:** Cycles

!!! warning "Обратите внимание"
    В EEVEE нет тени от пола: прозрачный ловец теней — фича Cycles. Модель будет висеть в пустоте, и это не поломка.

### Разрешение

![Разрешение](img/c/resolution.png){ .control-shot }

Размер кадра и две кнопки-стрелки: уменьшить вдвое и удвоить.

**Когда пригодится.** Стрелки сохраняют пропорции, поэтому рамка кадра во вьюпорте не прыгает. Уменьшите вдвое, пока ищете ракурс, и верните перед финальным снимком.

**По умолчанию:** 3840 × 2160

### Samples, Denoiser, Ground Shadow

![Samples, Denoiser, Ground Shadow](img/c/quality.png){ .control-shot }

Число сэмплов, шумоподавитель и тень от пола.

**Когда пригодится.** Сэмплов по умолчанию хватает для дейлика. Поднимать стоит, только если на финальном кадре виден шум в тенях.

**По умолчанию:** 128 сэмплов, OptiX, тень включена.

!!! warning "Обратите внимание"
    Без видеокарты NVIDIA денойзер OptiX сам заменяется на OpenImageDenoise — выбирать ничего не нужно.

### Output Folder и Name

![Output Folder и Name](img/c/output.png){ .control-shot }

Куда сохранять кадры и с какой основой имени.

**Когда пригодится.** Если папку не задать, аддон создаст `renders` рядом с файлом и покажет серым реальный путь под полями — так видно, куда всё уедет.

**По умолчанию:** имя `shot`; папка пустая.

!!! warning "Обратите внимание"
    К имени добавляется автонумерация, поэтому предыдущие кадры не затираются.
