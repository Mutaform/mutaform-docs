# QC Daily Render

Студийный рендер модели в одну кнопку — для дейликов, превью и портфолио. Аддон
строит вокруг вашей модели студию в духе Marmoset: HDRI-свет, единый материал,
контактная тень, пост-обработка. Снимает кадр ровно с того ракурса, который вы
видите во вьюпорте, и сохраняет PNG с прозрачным фоном.

Ничего в сцене при этом не ломается: **Restore** возвращает всё в исходное
состояние, включая настройки рендера.

![Панель Studio Render](img/panel.png){ .screenshot }

## Установка

Репозитория у этого аддона пока нет, ставится из файла.

1. Взять свежий `mutaform_studio_render_vX.Y.Z_extension.zip`
2. `Edit → Preferences → Get Extensions → ▼ → Install from Disk…`

Панель: ++n++ во вьюпорте → вкладка **QC Render**. Нужен Blender 5.2 или новее.

## Как снять кадр

1. **Setup Render Scene** — строится студия, вьюпорт переключается в Rendered,
   появляется рамка будущего кадра. До этого шага настройки в панели неактивны.
2. Летаете вьюпортом и ищете ракурс. Навигация работает как обычно.
3. **Render** — камера встаёт по текущему виду, рендерится то, что внутри
   рамки, PNG сохраняется с автонумерацией. Камера убирается, вид не сдвигается.
4. **Restore (exit)** — сцена откатывается полностью.

Кнопка **Open Folder** рядом с Render открывает папку с готовыми кадрами.

!!! tip "Рамка — это и есть кадр"
    Всё, что за рамкой, затемнено и в рендер не попадёт. Композиция строится
    прямо во вьюпорте, вслепую подгонять ничего не нужно.

## Настройки

Панель разбита на два блока.

### Camera Settings

**Use Default Material** — рендерить всё одним студийным материалом (цвет,
шероховатость, металличность настраиваются рядом). Так модель читается по
форме и силуэту. Выключите, если нужно показать собственные материалы.

Внутри свитка:

- **FOV** — вертикальный угол обзора. По умолчанию 15°, то есть длиннофокусная
  подача почти без перспективных искажений. Это то, что делает кадр похожим на
  студийную съёмку, а не на скриншот из вьюпорта.
- **HDRI Brightness / Rotation** — яркость и поворот окружения. Поворот меняет
  направление света и бликов вживую, модель при этом не двигается.
- **Post Effect** — Tone Mapping, Exposure, Highlights/Midtones/Shadows,
  Clarity, Contrast, Saturation.
- **Sharpen** — резкость с ограничителем, чтобы по краям не полезли ореолы.
- **Vignette**, **Frame Guide**, **Background** — цвет подложки в превью
  (на итоговый PNG не влияет, он прозрачный).
- **Wireframe** — сетка поверх шейдинга: цвет, толщина, непрозрачность.
  Показывает чистую топологию без треугольников триангуляции.

### Render Settings

Движок, разрешение (кнопки ×0.5 и ×2 сохраняют пропорции), сэмплы, шумодав,
тень от пола, папка и имя вывода.

## Скорость

При Setup аддон сам выбирает быструю конфигурацию под машину:

- лучший доступный бэкенд — OptiX, затем CUDA, HIP, oneAPI, Metal;
- только GPU, без гибридного режима с процессором;
- persistent data.

Нет видеокарты NVIDIA — денойзер OptiX сам заменится на OpenImageDenoise.

**EEVEE** — быстрый режим просмотра: та же сцена, но без тени от пола, потому
что прозрачный ловец теней есть только в Cycles.

Всё это восстанавливается при Restore, включая выбор устройств рендера.

## Прозрачный фон

Финальный кадр сохраняется с альфой, и контактная тень попадает в неё же.
Поэтому кадр композится на любой фон — тень ляжет правильно, а не квадратом.
