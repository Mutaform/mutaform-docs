# Установка — QC Maya Viewport

Ставится один раз, дальше Blender сам предлагает обновления.

## Что понадобится

Blender **5.1** или новее. Версию видно в заголовке окна Blender, а также
в `Help → About Blender`.

## Шаг 1. Добавить репозиторий

Это делается **один раз на машину**. Если вы уже добавляли репозиторий для
другого аддона Mutaform, всё равно добавьте — у каждого аддона он свой.

1. `Edit → Preferences…` — откроются настройки Blender
2. Слева выбрать раздел **Get Extensions**
3. В правом верхнем углу нажать значок шестерёнки → **Repositories**
4. В открывшемся окне нажать **+** → **Add Remote Repository**
5. В поле **URL** вставить ссылку:

    ```text
    https://mutaform.github.io/qc-maya-viewport/index.json
    ```

6. Поставить галочку **Check for Updates on Startup**
7. Нажать **Create**

Окно репозиториев можно закрыть.

![Как добавить репозиторий](../img/install-extension.gif){ .screenshot }

На записи показан пример с одним из аддонов — порядок кнопок для всех
одинаковый, отличается только ссылка. Ваша ссылка — та, что в шаге 5 выше.

## Шаг 2. Установить аддон

1. Оставаясь в **Get Extensions**, в строке поиска сверху набрать:

    ```text
    QC Maya Viewport
    ```

2. В списке появится аддон — нажать **Install** справа от его названия

Всё. Настройки Blender можно закрывать.

## Шаг 3. Проверить, что получилось

Этот аддон не живёт в N-панели. Он добавляет **иконку сферы в шапку
3D-вьюпорта**, справа от кнопок шейдинга: она включает режим, а стрелка
рядом раскрывает меню.

Если панель на месте — установка прошла.

## Обновления

Blender проверяет их сам при запуске, потому что на шаге 1 включена галочка
**Check for Updates on Startup**. Когда выйдет новая версия, она появится в
`Get Extensions` с кнопкой **Update**.

Проверить вручную: `Get Extensions` → шестерёнка → **Check for Updates**.

Версия установленного аддона написана в заголовке его панели справа, например
`ver 1.0.0`. Она же нужна, чтобы понять, ту ли документацию вы читаете —
переключатель версий стоит в шапке этого сайта.

## Если не получилось

| Что видно | В чём дело |
| --- | --- |
| В поиске ничего не находится | Репозиторий не добавился или ссылка вставлена с опечаткой. Вернитесь на шаг 1 и проверьте адрес целиком |
| Аддон в списке есть, но `Install` не нажимается | Ваш Blender старее, чем **5.1**. Обновите Blender |
| Установился, но панели нет | Проверьте, что нажали ++n++ именно во вьюпорте, и посмотрите вкладки сбоку: их бывает много, нужная может быть свёрнута |
| Список репозиториев пуст | Нет доступа в сеть или он закрыт прокси. Тогда попросите у студии архив и поставьте из файла: `Get Extensions` → значок `▼` справа сверху → **Install from Disk…** |
