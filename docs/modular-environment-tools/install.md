# Установка — Modular Environment Tools

Ставится из файла: репозитория расширений у этого аддона нет.

## Что понадобится

Blender **4.2** или новее.

## Шаг 1. Взять архив

Публичной ссылки на скачивание пока нет — архив
`modular_environment_tools_vX.Y.Z.zip` берётся у студии.

!!! info ""
    Аддон сторонний: автор — **Кирилл Харичев**, лицензия GPL-3.0-or-later.
    Студия ведёт свою ветку с доработками, и документация описывает именно её.
    Исходники: [оригинал](https://github.com/HarichevK/Modular-environment-tools),
    [студийная ветка](https://github.com/Mutaform/Modular-environment-tools/tree/studio/rework).

## Шаг 2. Поставить из файла

1. `Edit → Preferences…`
2. Слева выбрать раздел **Get Extensions**
3. В правом верхнем углу нажать значок `▼` → **Install from Disk…**
4. Выбрать скачанный архив

## Шаг 3. Проверить, что получилось

Нажмите во вьюпорте **++ctrl+shift+m++** — под курсором всплывёт панель.

Это основной способ работы: аддон задуман так, чтобы не занимать место на
экране постоянно.

!!! tip "Если удобнее вкладка сбоку"
    В настройках аддона (`Edit → Preferences → Add-ons`, найти **Modular
    Environment Tools**) есть галочка **Show in the sidebar**. С ней в боковой
    панели вьюпорта появляется вкладка **Modular** с тем же содержимым.

    Там же меняется и само сочетание клавиш.

## Обновления

Аддон, поставленный из файла, сам не обновляется. Новую версию ставят так же:
берут свежий архив и повторяют шаг 2 — Blender заменит установленную версию.

## Если не получилось

| Что видно | В чём дело |
| --- | --- |
| `Install from Disk…` не находится | Значок `▼` — в правом верхнем углу раздела **Get Extensions**, рядом с шестерёнкой |
| Поставился, но ++ctrl+shift+m++ ничего не открывает | Сочетание могло быть занято другим аддоном. Посмотрите в настройках аддона, какое стоит, и при необходимости задайте своё |
| Blender ругается при установке | Версия Blender старее 4.2 |
