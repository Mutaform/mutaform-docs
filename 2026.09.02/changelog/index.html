    Что нового¶

    Версии, из которых собрана эта документация. Номер в заголовке панели аддона должен совпадать с номером здесь — если он ниже, переключите версию документации в шапке сайта.

    Аддон Версия Требуется
    QC Bake 2.0.0 Blender 5.0+
    Scene QC Validator by Mutaform Studio 1.9.2 Blender 4.5+
    QC Daily Render 1.6.2 Blender 5.1.2+
    QC Maya Viewport 0.34.1 Blender 5.1+
    QC Bridge Maya-Blender by Mutaform 1.1.8 Blender 4.2+
    QC Bake for Maya 1.2.4 Maya 2025
    Modular Environment Tools 2.15.0 Blender 4.2+

    История изменений каждого аддона ведётся в его собственном репозитории; сюда она переносится вручную при обновлении документации.

    QC Bake¶

    2.0.0¶

    Major update - accumulated a batch of workflow fixes since 1.1.0, most notably making Reduce Bake Groups non-destructive.

    Added¶

    • Restore Bake Groups: a new button next to Reduce Bake Groups that undoes the most recent reduce pass, restoring every renamed object (and mesh datablock) to its prior name. The backup is stored on the objects themselves, so it survives file save/reload and outlives Blender's native undo stack - not just a Ctrl+Z.
    • Per-Asset health colors: in the Per Asset collection layout, each Bake_<name> collection is now color-tagged in the Outliner - green when it holds a complete low/high namepair, red when only a low or only a high is present (a member is missing or was accidentally deleted).
    • Version display: the add-on's version now shows right-aligned in the N-panel header ("ver X.Y.Z"), read live from blender_manifest.toml.

    Changed¶

    • Collection Layout (Flat & Per Asset): newly built collections are now automatically collapsed in the Outliner after organizing, instead of being left fully expanded.

    1.1.0¶

    • Initial tracked release: namepair creation, swap, visibility toggles, reduce bake groups, and Flat / Per Asset collection organizing.

    Scene QC Validator by Mutaform Studio¶

    1.9.2¶

    Каждый осмотр развёртки теперь ограничен одним материалом: один материал — один текстурный сет. Собраны изменения с 1.8.7.

    Добавлено¶

    • Review Scene: клик по имени материала выделяет все объекты сцены, где он используется, и делает его у них активным слотом.
    • Review Scene: кнопка с иконкой UV рядом с материалом изолирует его грани в режиме редактирования, так что в редакторе UV остаётся развёртка только этого материала. Повторное нажатие возвращает выделение, режим, синхронизацию UV и выделение внутри режима редактирования — какими они были до начала.
    • Список материалов продолжает описывать объекты, бывшие в области действия на старте осмотра, чтобы можно было переходить от материала к материалу, а Selection не схлопывался на тот, что сейчас смотрят.
    • Show Overlaps, Show Padding и Show Texel Density следуют за активным слотом материала: выбор другого слота в редакторе свойств (или другого материала в списке Review Scene) перенаводит запущенный осмотр на него, не выходя из режима редактирования, если тот же материал лежит на тех же мешах.
    • Под тремя переключателями появилась строка с именем материала, который сейчас смотрят; операторы называют его и в своих сообщениях.
    • Встроенный проект Mutaform_Default содержит студийный чек-лист для всех пяти стадий вместо устаревшей копии, в которой не хватало четырёх проверок.

    Исправлено¶

    • Налезание двух материалов на одном меше больше не считается и не рисуется как налезание: второй материал — второй текстурный сет, он волен лежать в UV-пространстве где угодно.
    • Полоса отступа идёт по следу осматриваемого материала. Ребро, где его грани сходятся с гранями другого материала, считается краем острова, а чужие острова больше не обводятся собственной полосой.
    • Плотность текселей меряется относительно средней по граням только осматриваемого материала, поэтому второй материал в другом масштабе больше не сдвигает всю окраску.
    • Редактор UV больше не показывает во время осмотра развёртки всех материалов — именно из-за этого мультиматериальный меш там было не прочитать.
    • Осмотр, открытый из строки результата, по-прежнему охватывает меш целиком, совпадая с тем, о чём сообщила проверка.
    • tools/build_release.ps1 собирал архив с разделителями «\» и без общей папки внутри — распаковать его могла только Windows. Теперь пишется обычный архив scene_qc_validator/ и рядом копия с номером версии.

    1.1.1¶

    • Fixed repeated UV checker restore on objects that originally had no materials.
    • Rebuilt the line checker texture as a 1024x1024 asset.
    • Added the add-on version label to the main panel header.

    1.1.0¶

    • Packaged as a Blender Extension.
    • Added scene and mesh validation checklist workflow.
    • Added preset import/export support.
    • Added UV checker assets and controls.
    • Added FBX export workflow with Mutaform preset.

    QC Daily Render¶

    1.6.2¶

    • Починен вылет Blender при рендере тяжёлых сцен. Временная камера убиралась прямо внутри обработчика окончания рендера, и удаление объекта в этот момент дёргало наполовину разобранный depsgraph. Теперь уборка откладывается на таймер и происходит в безопасный момент.
    • Минимальная версия Blender понижена с 5.2 до 5.1.2. Полный проход — установка студии, переключение движка, рендер и откат — проверен на 5.1.2.

    1.6.0¶

    • Аддон переименован в QC Daily Render. До этого у него было четыре разных имени: пакет и идентификатор расширения говорили mutaform_studio_render, панель — «Mutaform Studio Render», а папка проекта, репозиторий и адрес справочника — qc-daily-render.

    Обновление с версии 1.5.x не придёт само

    Вместе с именем сменился идентификатор расширения, поэтому Blender считает это другим аддоном, а не новой версией прежнего. Старую копию нужно удалить и поставить новую — порядок на странице установки.

    Modular Environment Tools¶

    Аддон сторонний: автор — Кирилл Харичев. Ниже — студийная ветка, из которой собрана документация; авторский master остаётся на 1.0.0.

    2.15.0¶

    • Import from file и Send to file внизу меню пресетов. Общая папка — опрятный способ передать пресет, файл — способ, который работает всегда.

    2.14.0¶

    • Пресеты стали общими: это обычный JSON в папке, которая задаётся в настройках. Направьте её на шару или в папку проекта — и все увидят одни и те же пресеты. Раньше они писались через собственную систему пресетов Blender, питоном в профиле художника, куда никто другой не дотянется.
    • Сцена помнит, из какого пресета настроена, и кнопка меню это показывает.
    • Пресет, записанный другой версией аддона, применяется в понятной части, а не отвергается целиком.

    2.13.0 — 2.12.0¶

    • Панель показывает заранее, во что превратится имя активного объекта: читать два поля и гадать — работа, показать результат — нет.
    • Коллизии пропускаются при дописывании размеров: их имя следует за модулем.

    2.9.0 — 2.11.0¶

    • Выгрузка в FBX: папка, файл на модуль, оси и масштаб.
    • Отчёт валидации фильтруется по важности, из строки выделяется объект, а All alike выделяет все объекты с такой же находкой.

    2.0.0¶

    Переработка аддона вокруг трёх вещей, которых у него не было: единого места для имён, меток на том, что он сам сгенерировал, и проверок с отчётом.

    • Вкладка Modular в боковой панели. Раньше у панели не было категории, поэтому вкладка не появлялась вовсе, и README просил художника повесить вызов на клавишу руками.
    • Настройки аддона с редактируемым сочетанием Ctrl + Shift + M.
    • Add selected to library — единственный инструмент, которому разрешено создавать коллекцию библиотеки.
    • Rebuild collisions, наборы Generated / Outdated / Orphans, Show / hide, Delete orphans — всё это стало возможным, потому что сгенерированные объекты теперь помечены источником и его отпечатком.
    • Validate scene: отчёт с уровнями важности, список в панели, выделение из строки.
    • Настройками стало то, что было константами: коллекция библиотеки, оба префикса, материал коллизии и его цвет, угол упрощения, поджатие.
    • Коллизии нумеруются: UCX_Wall_01, UCX_Wall_02.
    • Набор тестов, который гоняет сам Blender.

    1.0.0¶

    Первая версия автора: библиотека модулей, черновые коллизии, переименование UCX/UBX, размеры в именах, пакетное применение трансформа и развёртка.

    QC Bake for Maya¶

    1.2.4¶

    Иконка полки собирается из настоящего вектора icons_src/qc_bake.svg, поэтому каждый размер рисуется из исходника, а не пересчитывается из растра.

    Отгружается она всё равно в PNG, и вот почему. Maya действительно умеет брать .svg для кнопки полки, но рисует его через Qt, а тот реализует SVG Tiny — без <mask>. Элемент игнорируется, содержимое маски рисуется как обычная графика, и на этом файле зелёная заливка растекается по надписи, оставляя за собой белый прямоугольник. Замерено на настоящей кнопке: 29 % зелёного, 11 % белого. Поэтому PNG рендерит браузер, который спецификацию поддерживает целиком.

    1.2.2¶

    Открытие панели теперь всегда проверяет обновления. Ни отметки времени, ни интервала — только сам переключатель «Check on Open».

    В 1.2.1 была попытка сэкономить: запоминать, когда проверялись в прошлый раз, и пропускать недавние. Дважды на настоящей установке это дало единственный исход, который важен: инструмент знал, что устарел, и молчал. Открытие панели с полки — осознанное действие и лучший момент, чтобы услышать про обновление.

    1.2.0¶

    Своя иконка на полке Mutaform вместо стандартной.

    1.1.0 — 1.1.4¶

    Самообновление: панель спрашивает манифест на GitHub Pages, скачивает архив, сверяет контрольную сумму и подменяет папку без перезапуска Maya. Прежняя версия хранится, пока новая не загрузится.

    1.0.0¶

    Первый выпуск: полный паритет с расширением QC Bake для Blender 2.0.0 — создание пары, Swap High / Low, видимость по ролям, Reduce Bake Groups с обратимым откатом и обе раскладки аутлайнера.

    Сверх блендеровской версии появилось то, чего потребовала Maya: Count Smooth Preview (polyEvaluate не видит smooth mesh preview), Track Selection Order (у Maya нет активного объекта), распознавание маячьей автонумерации и сохранение неймспейсов при переименовании.

    QC Maya Viewport¶

    0.34.1¶

    • Наклон ключевого света возвращён. В 0.34.0 его направили точно по оси взгляда, опираясь на замер по плоскости, — но плоскость не показывает, откуда светят. Показывает шар: у Maya самая яркая точка на нём лежит выше центра на 15 % радиуса, значит свет наклонён. Без наклона затенение читалось так, будто освещение идёт не с той стороны.
    • Блик снова 0.30 — столько нужно наклону, чтобы дотянуться до уровня Maya.

    Известное расхождение: у blinn в Maya блик уже и поднимается над окружающей поверхностью примерно на 12/255, у здешнего Blinn-Phong — примерно на 5. Отличается форма пятна, не уровень.

    0.34.0¶

    • Воспроизведена тоновая кривая Maya, поэтому совпадает вся серая шкала, а не одна точка. В 0.33.0 средний серый подгоняли, занижая рассеянный свет, но Maya прогоняет вьюпорт через тоновую кривую (по умолчанию ACES 1.0 SDR-video), и никакой единый множитель за ней не угонится. Кривую сняли с Maya — surfaceShader прогнали по 16 известным значениям и считали с плейбласта — и вложили в шейдер. Худшая ошибка выше чёрного — меньше 1/255.
    • С кривой уровни стали такими же, как у Maya: рассеянный 0.4 (цвет blinn 0.5 × diffuse 0.8) и блик 0.22.
    • В Settings добавился переключатель Maya Tone Curve рядом с двумя уровнями — для Maya, настроенной на обычный sRGB вместо ACES.

    0.33.0¶

    • Серый во вьюпорте приведён к Maya. Уровни затенения были на глаз, теперь замерены: плоскость, повёрнутая к камере и залитая стандартным blinn (цвет 0.5, diffuse 0.8) под стандартным налобным светом, читается в Maya 2025 как 146/255, а с бликом — 179/255. QC-вьюпорт рисовал 183 и 187, то есть заметно светлее.
    • Оба уровня вынесены в Settings под заголовком Maya Match.

    0.32.0¶

    • Галочка рядом с Find Textures, по умолчанию включена. Одно нажатие заполняет все материалы на всех выделенных объектах, так что набор, приехавший двумя десятками односоставных мешей, собирается за один заход, а не за двадцать. Снимите её, чтобы заполнялся только активный слот. Состояние запоминается.
    • Починено: файлы, разложенные по плиткам UDIM (bake_1001_ao, bake_1002_ao), сливались в одно тайловое изображение, и каждому материалу доставалась плитка 1001. Теперь, когда номер плитки стоит в имени материала (vzor_1002), файлы считаются разными наборами и каждый материал берёт свой.

    0.31.0¶

    • Починено: Find Textures не открывался на папке импортированного меша. Ошибок было две. Отслеживание импорта читало путь из истории операторов, куда Blender импортёры не кладёт вовсе; теперь путь берётся из свойств, с которыми импортёр вызывался последний раз, — там он есть. И обработчик не был помечен постоянным, поэтому Blender выбрасывал его при открытии любого .blend.
    • Если у объекта пути нет, а поиск по имени ничего не нашёл, браузер открывается на папке последнего импорта, а не в пустоте. Это закрывает всё, что было импортировано до этой версии.

    0.30.4¶

    • Починено почерневшее в части сцены изображение. Режим Roughness Only добавил в шейдер пять push-констант, из-за чего матрица нормалей MAT3 сдвинулась внутри блока констант и в вершинную стадию поехал мусор — объекты чернели во всех режимах, включая Default Material. Матрица теперь MAT4, у которой выравнивание однозначно.
    • Все текстуры собираются до того, как назначен хоть один сэмплер: создание текстуры между назначениями сбивало уже занятые слоты.
    • Изображение с потерянным файлом уходит в плоскую заливку, а не отдаётся на видеокарту чёрной текстурой.

    0.30.1¶

    • Откат 0.30.0. Выпадашка в шапке снова панель-поповер: превращение её в меню действительно выровняло подписи по левому краю, но выглядело и работало хуже. Blender центрирует подписи кнопок в поповере, и настройки для этого нет.

    0.29.1¶

    • При включении режима соглашение о зелёном канале считывается с нод Normal Map в сцене. Настройка вьюпорта живёт в модуле, поэтому раньше она сбрасывалась на OpenGL при каждой перезагрузке аддона, пока ноды оставались на DirectX, — и они молча расходились.

    0.29.0¶

    • OpenGL / DirectX переключают и ноды Normal Map, так что обычный рендер в EEVEE и Cycles согласуется с QC-вьюпортом, а не остаётся при своём. Двигаются все ноды в материалах сцены, включая лежащие внутри групп; правка отменяется.

    0.28.1¶

    • Починен сбой Find Textures на материале без упакованных карт: сборщик упакованных карт возвращал одно значение там, где ждали два, и набор из обычных _ao + _normal падал с TypeError. Материал оставался собранным наполовину; повторный запуск Find Textures его дособирает.

    0.28.0¶

    • Find Textures открывается на папке самого ассета, а не в произвольном месте. Blender путь импорта выбрасывает, поэтому работает это с двух сторон: путь всего, что импортируется с этого момента, записывается на объект, а уже лежащее в сцене ищется по имени под папками Project Roots из Settings. Находка внутри подпапки Meshes поднимается на уровень выше — туда, где действительно лежат карты.
    • Нормали, запечённые в объектном пространстве (_normalobj, _objnormal, _normalworld, _worldposition), игнорируются наравне с прочими служебными.

    0.27.0¶

    • Новый режим Roughness Only — в меню сразу после AO Only. Показывает шероховатость плоской заливкой, доставая нужный канал из упакованной _ORM/_MRO/_spec или из синего канала _NRM. Материал без шероховатости читается средним серым, а не белым.

    0.26.1¶

    • Каждая правка таблицы суффиксов помечает настройки изменёнными. Без этого строки, добавленные или удалённые кнопками +/-, могло выбросить при выходе автосохранением настроек.
    • Диалог настроек говорит, сохраняется ли таблица, и предлагает кнопку Save Preferences, когда автосохранение выключено.

    0.26.0¶

    • Новый пункт Settings внизу меню: таблица суффиксов стала редактируемой. Поменять, на что отображается суффикс, добавить свой или удалить, чтобы он перестал распознаваться. Заполнена 104 встроенными правилами, есть сброс.
    • Доступна также как Suffixes в боковой панели Find Textures и из настроек самого аддона. Правила лежат в настройках Blender, поэтому переживают перезапуск и действуют во всех сценах на машине.

    0.25.1¶

    • Починено: вьюпорт мог залипнуть включённым. Дескриптор GPU-отрисовки жил только в переменной модуля, поэтому перезагрузка или отключение аддона при работающем просмотрщике оставляли обработчик сиротой — он продолжал рисовать, и выключить его было уже нечем. Теперь дескриптор хранится там, где перезагрузка его не потеряет, при регистрации подметаются осиротевшие, а отключение аддона гасит просмотрщик.

    0.25.0¶

    • _spec читается как упакованная Metalness / Roughness / AO, как в студийных поставках, а не как уровень бликов.
    • _cc (маска тонирования) и запечённые _curve, _cavity, _thickness, _objid, _matid, _position, _id не подключаются никогда.
    • Починено: папка из браузера приходит с разделителем на конце, из-за чего не срабатывало правило «файл без суффикса — это базовый цвет».

    0.24.0¶

    • Поддержка _NRM — формата поставки, где R и G держат нормаль, а B — шероховатость. Распаковывается группой нод MVM Unpack NRM, восстанавливающей Z как sqrt(1 - x² - y²); QC-вьюпорт восстанавливает тот же Z на видеокарте. Обычные _Normal плюс _Roughness в той же папке по-прежнему выигрывают.
    • Распознаются _COL и _NM.
    • Файл вообще без суффикса считается базовым цветом, если рядом лежит одноимённый файл с суффиксом.
    • Если в наборе есть _AO, но нет ничего для диффуза, AO уходит в Base Color.
    • Файл из выбранной папки выигрывает у такого же из подпапки: полноразмерные карты берут верх над копией из 1k.
    • Имя файла, в котором написано OpenGL или DirectX, задаёт соглашение и ноде Normal Map, а не только вьюпорту.

    0.23.0¶

    • Новое: Find Textures. Выделите объект и слот материала, укажите папку с картами — и текстуры подключатся в Principled BSDF по суффиксам в именах. Карты данных получают Non-Color, нормаль идёт через ноду Normal Map, высота через Bump, упакованные _ORM-подобные разбираются по каналам.
    • Когда в одной папке несколько наборов, берётся тот, чьё имя совпадает с материалом; если совпадения нет — что лежит, то и назначается.
    • Уже подключённые текстуры перенаправляются, а не дублируются, а .psd выигрывает, только если ту же карту не несёт ничто другое.
    • Настройки: искать во вложенных папках, сверять имя материала, заполнять все слоты, читать соглашение о нормалях из имени файла.

    0.22.8 и раньше¶

    Диагностический GPU-вьюпорт: Normal Only, Normal + AO, AO Only, Default Material, соглашение OpenGL/DirectX, Reimport Textures.
